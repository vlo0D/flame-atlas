# Журнал використання AI (SI)

Поле «Use of Super Intelligence (SI)» у формі подання обов'язкове. Кожен дописує сюди рядок,
коли використав AI для чогось суттєвого. Роль E у неділю збирає з цього текст англійською.

## AI під час підготовки даних

| Місце | Інструмент і модель | Що робить | Як обмежено й перевірено |
|---|---|---|---|
| Маппінг таблиць | Claude Code (Claude Opus 5.5, Claude Fable 5.2) | пропонує відповідність колонок полям контракту й одиниці | маппінг — JSON, який читає людина; застосовує детермінований код; скрипт звірив понад 2 100 значень з клітинками; ручна вибірка 40 значень ще не перевірена |
| Умови, яких немає в таблиці | Claude Code (Claude Opus 5.5, Claude Fable 5.2) | знаходить значення в інших файлах того самого дослідження (матриця тестів BASS, телеметрія SAFFIRE і SAME-R, звіт SPICE) і пише правило поєднання | значення переносить код; поле позначене в `inferred`, клітинку процитовано в `notes` |
| Нотатки оператора BASS | Claude Fable 5.2 у сесії Claude Code | читає вільний текст і визначає займання, наслідок і час горіння | код приймає значення лише з дослівною цитатою; відкинуте йде в `data/review/si-notes-rejected.csv`; вибірка 20 значень для людини |
| SI brief для сценаріїв | Claude Fable 5.2 у сесії Claude Code | пише кілька речень про готовий сценарій з фактів, які порахував сайт | кожне число й назву звіряє код у тесті й у браузері; речення, що не пройшло, не показується |
| Тексти карток | модель не використовується | речення беруться дослівно з метаданих PSI (`pipeline/cards.py`) | кожну цитату шукає код у тексті джерела |

Під час роботи сайту модель не викликається: brief і прочитання нотаток зроблено наперед і лежать у репозиторії.
Ранжування, карту покриття й прогалини рахує код.
