# Журнал використання AI (SI)

Поле «Use of Super Intelligence (SI)» у формі подання обов'язкове. Кожен дописує сюди рядок,
коли використав AI для чогось суттєвого. Роль E у неділю збирає з цього текст англійською.

## AI під час розробки

| Коли | Хто (роль) | Інструмент і модель | Для чого | Як перевірили результат |
|---|---|---|---|---|
| 14.11 | усі | AI-асистент | дослідження підходів, план робіт, списки задач команд, чернетка контрактів | прочитала й погодила команда |
| 14.11 | Продукт | Claude Code (Claude Fable 5.2), BMAD 6.12.4 | архітектурні правила сайту (`ARCHITECTURE-SPINE.md`), каркас сайту в `apps/web` (п'ять екранів, шлюз даних, базові функції `src/domain`), світла й темна тема | лінтер BMAD і два незалежні рецензенти для архітектури; 43 модульні тести, ESLint, перевірка типів, статична збірка; обидві теми переглянуто в браузері |
| 14.11 | Продукт | Claude Code (Claude Fable 5.2) | ранжування досліджень під середовище (`apps/web/src/domain/rank.ts`), форма сценарію й картки результатів | 94 модульні тести, зокрема перевірка порядку для місячної бази з `docs/01-product-spec.md`; ручна перевірка в браузері локальної й статичної збірки; ваги предметник не перевіряв |
| 14.11 | Продукт | Claude Code (Claude Fable 5.2) | фільтри таблиці тестів, сітка покриття, розрахунок прогалин і блок зі знахідкою | 125 модульних тестів, зокрема що посилання біля прогалини відкриває рівно ті рядки, які вона порахувала; перевірка в браузері |
| 15.11 | Дані й AI | Claude Code (Claude Opus 5.5) | інвентар файлів PSI: знайдено запит повного дерева файлів `files/v2`, скрипт `pipeline/inventory.py`, класифікація файлів на потрібні й непотрібні, звіт `docs/11-psi-inventory.md` | сума розмірів з дерева збігається з `totalFileSize` метаданих; списки `need` і `maybe` переглянуто вручну, правила класифікації виправлено після перегляду |

## AI під час підготовки даних

| Місце | Інструмент і модель | Що робить | Як обмежено й перевірено |
|---|---|---|---|
| Маппінг таблиць | | пропонує відповідність колонок полям контракту й одиниці | маппінг читає автор; застосовує детермінований код; інша людина звіряє 5 рядків; ручна вибірка 40 значень |
| Назви матеріалів | | розбирає рядок на матеріал, форму, розміри | словник читає людина |
| Тексти карток | | пише опис із полів метаданих PSI з дослівними цитатами | кожну цитату шукає код у тексті джерела; вибірка 48 тверджень |

На самому сайті LLM не викликається. Ранжування, карту покриття й прогалини рахує код.
