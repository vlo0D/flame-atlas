## 2. `qa-tests.csv` — вибірка тестів

Заголовок файла:

```
id,field,expected,actual,ok,note
```

- `id` — id запису з `tests.json`;
- `field` — шлях поля, наприклад `atmosphere.o2Pct`;
- `expected` — значення, яке ти бачиш у вихідному CSV (з одиницею);
- `actual` — значення в нашому записі;
- `ok` — `1` або `0`;
- `note` — що не так.

Обсяг: 40 значень, по кілька записів з кожної великої таблиці. Поля: паливо, O₂, тиск, потік, наслідок.
Підсумок (скільки перевірено і скільки правильних) іде в `meta.json`, поле `quality`.

## 3. `qa-cards.csv` — вибірка тверджень з карток

```
investigationId,section,claim,sourceId,locator,found,faithful,note
```

- `found` — `1`, якщо твердження є в джерелі за вказаним місцем;
- `faithful` — `1`, якщо зміст передано без посилення чи спотворення.

Обсяг: по 2 твердження з кожної картки.

## 4. `findings.md` — знахідка з числом

Числа для головного екрана й слайдів, пораховані з `tests.json` (задача DA-14). Для кожного числа:
значення, як його рахували, перелік id рядків. Обов'язкові пункти:

- скільки окремих тестів твердих матеріалів проведено при кисні ≥ 30% і тиску ≤ 70.3 кПа;
- скільки тестів проведено при частковій гравітації і скільки її імітували;
- який тест найближчий до сценарію місячної бази і чим він відрізняється;
- у скількох рядках не вказано тиск або потік.

## 5. `pillars.md` — напрям безпеки кожного дослідження

Таблиця на 24 рядки: `ID, основний напрям, додаткові, чому (джерело)`.
Початкова гіпотеза лежить у `docs/03-data-sources.md`, розділ 3.

## Вибірка прочитань SI: `si-notes-sample.csv`

20 значень, які мовна модель прочитала з нотаток оператора BASS (`python3 -m pipeline.review_si_notes`).
У кожному рядку: значення в даних, слова, які процитувала модель, і вся нотатка з файла NASA.
Код уже перевірив, що цитата є в нотатці. Людина перевіряє інше: чи значення справді випливає з нотатки.
Заповніть `checked_by` і `correct` (`yes` / `no`); підсумок запишіть у `quality` в `pipeline/config/contract.json`.
Правила, за якими читала модель: `pipeline/mappings/si/README.md`.

`si-notes-rejected.csv` — прочитання, які код відкинув, з причиною. Порожній файл означає, що відкинутих немає.
