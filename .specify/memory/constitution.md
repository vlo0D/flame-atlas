# Flame Atlas — конституція (Spec Kit)

Цей файл — точка входу Spec Kit (`/speckit.constitution`). Принципи не дублюються:
джерело правди — [`AGENTS.md`](../../AGENTS.md), розділ 2 «Незмінні принципи».

Кожна специфікація в `specs/NNN-*/` перед планом проходить «Constitution Check» з цих пунктів:

| # | Принцип (AGENTS.md §2) | Що перевіряємо в плані |
|---|---|---|
| 1 | Жодного твердження без джерела | кожен вихідний запис несе посилання на файл, сторінку, рядок |
| 2 | `null` краще за здогад | невідоме значення = `null`, не `0` і не `""` (крім `raw`) |
| 3 | AI пише маппінг, код застосовує | у фічі немає викликів LLM на рядок |
| 4 | `raw` зберігається завжди | вихідні клітинки дослівно + номер рядка |
| 5 | Цитати перевіряються програмно | текст зберігається дослівно, щоб цитату можна було знайти |
| 7 | Контракт — єдине джерело правди | фіча не змінює `contracts/`; проміжні формати мають свою схему |
| 9 | Мінімум інфраструктури | без БД і серверів; файли на диску |
| 11 | Продукт англійською | код, коментарі, коміти — англійською |
| 12 | Сирі дані PSI не чіпаємо | папка `Raw Data` виключена за замовчуванням |

Процес фічі: `spec.md` → `plan.md` → `tasks.md` → реалізація. Відхилення від принципу
записується в розділі «Complexity Tracking» плану і в `docs/decisions.md`.
